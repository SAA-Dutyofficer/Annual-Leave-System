🔧 Leave Balance Recalculation Tool (v2 — date-range matching)

Recomputes every employee's used-days counters from their actual approved leave requests that fall inside their CURRENT cycle dates. Use this after the auto-renewal double-fire bug — it does not rely on cycleId, only on cycleStart/cycleEnd, so it works even for employees whose cycleId got regenerated multiple times.

Manager login required. This tool writes directly to the employees collection. Nothing is changed until you review the preview below and click "Apply Corrections." An audit log entry is created summarizing every change made.

Before running this: make sure you've already deployed the staff.js fix that removes the listenForAutoRenewal() call — otherwise cycles could keep shifting underneath you while you're trying to fix them.
